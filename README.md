# 📊 Superstore Sales Dashboard | Tableau

> An interactive Tableau dashboard built to analyze Superstore sales data and uncover business insights related to sales, profit, customer segments, and regional performance.

---

## 🚀 Project Overview

This Tableau dashboard provides a comprehensive analysis of Superstore sales data. It helps visualize sales performance across different regions, customer segments, product categories, and time periods through interactive dashboards.

---

## 🎯 Objectives

- Analyze overall sales performance
- Monitor profit trends
- Compare regional sales
- Analyze customer segments
- Identify top-performing product categories
